# buy-research: 구매 전 리서치 멀티에이전트

사고 싶은 물건과 예산을 넣으면 **클리앙(본문과 댓글)**, **뽐뿌(본문과 댓글)**, **다나와 리뷰(낮은 별점 우선)**를 조사해서
후보 제품 **비교표와 구매 링크**를 만들어 줍니다. 최종 선택은 사용자가 합니다.

## 구조

```
           ┌──────────────────────┐
 query ──▶ │ 1. 플래너 에이전트      │  공식몰과 가격비교 사이트에서 예산 안의 후보 3~6개, 가격, 구매 링크를 찾음
           └─────────┬────────────┘
                     ▼  (병렬 실행, 에이전트마다 자기 사이트 도메인만 검색)
   ┌─────────────┬───────────────┬──────────────────┐
   │ 클리앙 에이전트│  뽐뿌 에이전트   │  다나와 에이전트      │
   │ 본문+댓글     │ 핫딜·댓글·최저가 │ 별점 1~3점 리뷰 우선  │
   └──────┬──────┴───────┬───────┴─────────┬────────┘
          ▼              ▼                 ▼
           ┌──────────────────────┐
           │ 3. 종합 에이전트        │  구조화 출력(Pydantic)으로 비교표, 적합도, 추천, 주의사항을 만듦
           └─────────┬────────────┘
                     ▼
        out/YYYY-MM-DD-<query>.md / .json
```

- Claude API 서버 툴(`web_search`, `web_fetch`)을 쓰고, `allowed_domains`로 각 에이전트의 검색 범위를 자기 사이트로 제한합니다.
- 사이트별 에이전트는 `asyncio.gather`로 동시에 돌아가고, 하나가 실패해도 나머지 결과로 비교표를 만듭니다.
- 모든 주장에는 근거 URL을 붙이고, 근거가 없는 사이트는 "언급 없음"으로 표시합니다. 내용을 지어내지 않도록 프롬프트에서 막아 두었습니다.

## 사용법

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...        # 또는 `ant auth login`

python -m buy_research "이케아 겨울 이불" --max-price 100000
python -m buy_research "로봇청소기 물걸레" --max-price 600000 --out out
```

## 파일

| 파일 | 역할 |
|---|---|
| `buy_research/pipeline.py` | 오케스트레이터 (플래너 → 사이트별 병렬 조사 → 종합) |
| `buy_research/agents.py` | 웹 검색 에이전트 실행기(`pause_turn` 이어 하기, 거부 시 대체 모델로 재시도)와 구조화 파서 |
| `buy_research/prompts.py` | 에이전트별 역할 프롬프트. 사이트를 추가하려면 `SITE_ROLES`에 한 줄만 넣으면 됨 |
| `buy_research/models.py` | 비교표 스키마 |
| `buy_research/render.py` | 마크다운 비교표 출력 |
| `reports/` | 조사 결과 예시 |
